Respaldo completo del sitio

Genera un archivo .zip con todo el sitio listo para mover a otro equipo: código fuente, plantillas, archivos estáticos, imágenes subidas y la base de datos completa.

Incluye
  • Base de datos completa (instance/photogame.db)
  • Imágenes y videos subidos (uploads/)
  • Todo el código fuente (.py, rutas, etc.)
  • Plantillas HTML (templates/)
  • Archivos estáticos (static/)
  • Configuración (requirements.txt, config.json, vapid_keys.json)
  • Scripts de arranque (.vbs, .bat, .ps1)
No incluye
  • Caché de Python (__pycache__)
  • Certificados SSL (cert.pem, key.pem)
  • NSSM y utilitarios de servicio (nssm-2.24/)
  • Entorno virtual (venv/)
  • Repositorio git (.git/)
Para restaurar en otro equipo: descomprime el ZIP, instala las dependencias con pip install -r requirements.txt y ejecuta python app.py (o usa los scripts .vbs/.bat).
